# cupido-backend

Módulo de preferencias del usuario.  

Administra la configuración personal de cada usuario, como intereses, edad preferida, ubicación o género de búsqueda.  

Este requerimiento sirve para ajustar los criterios de compatibilidad y mejorar la experiencia en las recomendaciones.



# cupido-backend

Módulo de gestión de fotos de usuario.  

Permite subir, actualizar, listar y eliminar imágenes del perfil.  

Este requerimiento se utiliza para que los usuarios personalicen su perfil con fotos que mejoren la interacción en la plataforma.
